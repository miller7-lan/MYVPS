# 邮件与删除用户

当前服务器版本为 `44c4d8af9b0330dc3de527fd`。管理员已在App自行填写授权码，完成真实邮箱验证码验证及测试通知；两封邮件均由SMTP接受，用户已确认邮箱联通。线上用户尚未执行删除，删除行为的验证来自隔离测试。

## QQ 邮箱

在 App「通知 → 发件设置」填写完整的发件账号和管理员收件地址。QQ 默认使用 `smtp.qq.com`、465、SSL；也支持强制 STARTTLS 的587及其他支持加密SMTP的服务。

在 QQ 邮箱官方页面开启相应服务并取得授权码，由本人填入 App 的「邮箱授权码」安全输入框，完成系统身份确认后保存。授权码不是QQ登录密码，不要发到聊天、工单或提交到GitHub。App不会在本机保存授权码，服务器仅在受限600账本中的私密表保存；普通快照、操作日志和配置导出不包含它。

保存后按顺序操作：

1. 选择「管理员邮箱」或已设置邮箱的普通用户，发送验证码。
2. 在实际邮箱中读取验证码，填入App并确认。验证码10分钟有效，最多尝试5次。
3. 点击发送测试邮件，查看历史结果及实际收件箱、垃圾邮件目录。

未填授权码时显示待配置，未验证收件地址时不发送测试和自动通知。验证码仅出现在实际邮件中，管理接口不会返回验证码正文。通知偏好支持启停、冷却时间和重试次数。

发送由VPS独立后台执行，Mac关闭后仍继续。通知包括个人用量阈值、超额、额度刷新及可识别的健康异常；管理员规则刷新与真实服务商重置使用不同事件。服务商API未接入时，不伪造商家刷新邮件。

排队表示任务已持久保存，SMTP接受表示发件服务器已接收，实际送达以收件箱为准。失败会记录脱敏错误码并按退避策略重试；发送后断线等极端情况仍可能重发，不承诺收件端恰好一次。邮件不含代理密码或完整订阅链接。

QQ SMTP配置来源：[腾讯云官方文档](https://intl.cloud.tencent.com/zh/document/product/1266/71700)。QQ邮箱服务入口：[mail.qq.com](https://mail.qq.com/)。

## 删除用户

在「用户 → 更多 → 删除用户」确认范围并完成系统身份认证。删除会撤销该用户的VLESS、TUIC和订阅凭据，从默认列表移除，保留流量账本及审计记录；可切换查看已删除用户。

删除请求提交后还需等待服务器确认实际停止。界面若提示停止待确认或失败，不能据此认定旧会话已经断开。最后一位管理员不能删除。已撤销身份不会因恢复旧配置重新有效。

当前试运行资源不会自动回收，重新添加用户需重新授权服务器资源。删除不会减少已经发生的本期实际用量，也不会清理历史账本。

## App 安装与文件访问

若项目位于iCloud同步的Documents，文件服务可能附加Finder属性并干扰应用签名。可直接构建到用户Applications：

```sh
bash macos/build-app.sh "$HOME/Applications/DazzleVPS.app"
```

更新后若App无法读取已有私钥，可在设置中重新选择同一个私钥文件再连接。无需复制密钥、放宽服务器指纹验证或授予整盘访问权限。
