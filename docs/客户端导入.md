# 客户端导入

仓库只提供公开示例，不能直接连接服务器。示例中的 `192.0.2.10` 是文档地址，UUID、公钥、短 ID 和密码也都是占位值。请使用**自己部署后生成的私密订阅地址**；不要把真实订阅、密钥或二维码提交到公开仓库、在线订阅转换网站。

默认节点为 **Dazzle'VPS-VLESS（常用）**，备用节点为 **Dazzle'VPS-TUIC5（迅速）**。名称中的“迅速”仅用于区分节点，不代表所有网络下都会更快。

## Shadowrocket

1. 在首页添加自己的节点订阅，即私密服务提供的 `nodes.txt` 地址。确认订阅中有上述两条节点。
2. 在“配置”页添加自己的规则地址，即 `config.conf`，导入后启用。
3. 首页“全局路由”选择 **配置**；在 **Dazzle'VPS** 分组选择 **常用**，再开启连接。连接不顺畅时，可在同一分组切换到 **迅速**。

[Shadowrocket 示例](../client/shadowrocket.example.conf) 保留 621 条规则、Host 和网址重写，只包含分组和分流，不内嵌节点。请先添加订阅，且节点名称必须与分组引用完全一致。这样可避免因配置内嵌节点而出现重复的首页订阅卡片。使用自己的文件导入时，同样遵循“先节点、后规则”的顺序。

国内、局域网及 Tailscale 按规则直连，其他请求按配置转发。更新节点后，可检查分组仍选中“常用”。订阅流量显示与本机实时速度是两项不同统计。

## Clash Verge Rev／其他 Mihomo 客户端

从 [Clash Verge Rev 官方发布页](https://github.com/clash-verge-rev/clash-verge-rev/releases/latest) 下载对应系统版本。应用支持远程订阅和本地配置导入，具体界面可参考 [官方订阅导入说明](https://www.clashverge.dev/guide/profile.html)。

1. 在“订阅”页添加自己的 **`clash.yaml` 远程地址**，命名为 `Dazzle'VPS`，导入后选择并启用这份配置。
2. 模式选择 **规则／Rule**；在 **PROXY** 分组中选择 **Dazzle'VPS-VLESS（常用）**，需要时改选“迅速”。
3. 浏览器通常使用 **系统代理**。命令行程序没有使用系统代理时，可按应用提示开启 **TUN**；同一设备同时只启用一个客户端的网络接管功能。两者的适用范围见 [官方快速入门](https://www.clashverge.dev/guide/quickstart.html)。
4. 保留配置中的局域网、Tailscale 及服务器地址直连规则。遇到证书错误时，应检查证书和服务器配置，保持证书验证开启。

[Mihomo 示例](../client/mihomo.example.yaml) 包含两种协议及 620 条规则，使用自己的参数替换示例值后，也可作为本地配置导入支持相应协议的 Mihomo 客户端。原 Shadowrocket 配置中的一条 `USER-AGENT` 规则及网址重写未移植。不要用节点链接转换结果覆盖这份完整分流配置。

## 剩余流量

远程订阅可以通过 `Subscription-Userinfo` 响应头提供用量：`upload`、`download`、`total` 单位为**字节**，`expire` 为可选的 Unix 秒时间戳。Clash Verge Rev 会在订阅卡片中展示这些信息；本地示例文件不会产生动态额度。[官方响应头说明](https://www.clashverge.dev/guide/url_schemes.html#subscription-userinfo)

若自己的部署使用服务器网卡统计，显示的是**全设备、全部协议共享的估算用量**。500,000,000,000 字节约等于 465.66GiB；GB 与 GiB 的显示差异不代表丢失流量。网卡 RX＋TX 可能包含系统更新、管理连接及转发流量，与商家的单向／双向计费、重置日期不同；安装统计前的流量也无法补录。以商家后台为准，并在订阅更新后查看新数值。
