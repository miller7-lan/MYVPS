# 公开注册与 Mac 人工放行

本功能已在本地实现及隔离测试，尚未部署到服务器。现有名单、凭据与SSH保持；原443/8443及旧目录已由管理员自行清理，不自动重建。

## 用户如何使用

1. 打开`https://你的服务器:9443/portal/`，填写邮箱和可选昵称，输入实际收到的验证码。邮箱验证成功即绑定账号；普通用户不提供SMTP授权码。
2. 注册确认邮件只提示等待审核。个人网页能查看预生成的Clash/mihomo和Shadowrocket固定订阅地址，但未启用时两者均403，不返回节点；请勿提前导入。
3. 管理员在Mac App“注册申请”中查看邮箱、额度、资源和总量分配，完成系统身份确认后点击启用。
4. 服务器完成独立资源、凭据、配置、可信计量及运行检查后，原订阅地址生效，并首次发送含两条完整地址的开通邮件。审核请求已提交不等于开通成功。
5. 普通停用再恢复不会重复首次开通邮件；停止、撤销、轮换时，队列不能继续发送已失效的链接。SMTP接受不等于收件箱实际送达。

Clash/mihomo使用`config.yaml`，Shadowrocket使用`nodes.txt`；完整Shadowrocket规则配置仍可由管理端导出`config.conf`。每份订阅包含VLESS REALITY（常用）和TUIC v5（迅速）。订阅包含凭据，转发邮件或二维码可能使其他人取得访问权限。

## 审批及资源

第一批新增5个普通用户槽，代理TCP/UDP24432–24436，对应统计接口127.0.0.1:34432–34436。保留现有两个槽；未启用的新增槽不运行额外核心，申请本身不占槽。资源用完时申请保持等待资源，不创建共享凭据或擅自开新端口。

普通默认100GB，沿用每月24日16:19 Asia/Shanghai管理员周期，与QQG实际周期分别记录。五个新增用户全部各100GB已达到500GB，尚未包括现有普通用户和管理员；App会提示超配风险，额度可在启用前调整。

## 权限和数据

公网只有注册、邮箱登录、自己的状态与订阅；管理员审批始终通过Mac的既有SSH入口。网页独立低权限账号不能读取SMTP授权码、完整账本或管理socket，只能调用限定Unix API。只读订阅/会话查询不占SQLite写锁。

验证码10分钟有效、60秒重发冷却、最多5次尝试；另有邮箱、来源及总发信限额和队列上限。会话独立随机、数据库存哈希、7天到期，Cookie为Secure/HttpOnly/SameSite；写请求校验Origin及CSRF。连接、握手、请求头、请求体设有限期限，订阅保留每IP限流。

未审核不会生成代理凭据，也不能因网页访问、邮箱扫描或周期刷新而启用。永久撤销墓碑、已有用量及历史账本不会因回退恢复。

## 上线与恢复

此前[门户上线与恢复](../deployment/门户上线与恢复.md)中的停止普通用户维护流程已撤回，不能直接执行。最新约束是保持现有名单的代理功能：阶段A由目标机一次性协调器先启动逐用户独立计量保护器和只读预热writer，在保留Core PID、连接、凭据和绝对计数的前提下，经同一把锁交接（policy保持v1）；阶段B再另行批准注册资源。协调器已通过隔离Linux/systemd演练，上线仍须新的明确审核清单；不移除保护、不伪造心跳或放宽5秒时效。

回退为关闭注册和登录入口、保留订阅服务；只重启9443，不重启agent或代理，不恢复旧数据库、不重放旧凭据。完整旧版程序不支持v2资源池，不能直接覆盖回退。

商家安全组及新端口外网连通需另外核实，不能由现有SSH推断；不使用浏览器Cookie替代商家API权限，也不自动更改商家设置。
