# Dazzle'VPS V3.1：服务器使用

新程序已于 2026-10-25 并行部署到 VPS，后台与新用户实例正在运行。真实双协议、订阅和额度流程仍在验收，本文不表示最终验收已通过。原 443 代理和 8443 订阅继续可用，不由新程序自动撤回。

## 连接管理界面

1. 打开本次交付的 `DazzleVPS.app`，进入“设置”。App 只管理服务器，不提供本地演示或本地模拟数据库。
2. 填写“服务器地址”，选择“已有 SSH 私钥文件”。复用现有管理身份；密钥只引用，不复制。若密钥有口令，先在系统 SSH agent 中解锁。
3. 点击“连接服务器”，核对“已固定的服务器身份” UUID 与本次部署记录一致。未知或变化的 SSH 指纹、不同的服务器身份会被拒绝，不能跳过核对。
4. 连接后查看“概览”和“用户”。未连接时不会生成示例用户，也不会显示本地演示用量。敏感变更和私密导出需要 Mac 系统身份确认。

App 使用现有 SSH 调用固定的 `/usr/local/bin/dazzle-vps-control rpc`，只传递 JSON 请求。它不安装后台、不修改 SSH 或防火墙，也没有旧代理退役入口。关闭 App 不会停止服务器后台、代理或订阅服务。

## 入口与范围

| 入口 | 作用 |
| --- | --- |
| TCP／UDP 24430 | 新管理员用户：VLESS／TUIC，共用一份用户载荷统计 |
| TCP／UDP 24431 | 新普通用户：VLESS／TUIC，共用一份用户载荷统计 |
| TCP 9443 | 新私密 HTTPS 订阅，凭令牌取文件，没有管理接口 |
| 127.0.0.1:34430、34431 | 服务器内部计量 API，不向公网开放 |
| 原 TCP／UDP 443、TCP 8443 | 继续保留的原代理和订阅，不属于新用户额度控制范围 |

首轮只有根策略批准的管理员、普通用户两个实例槽。增加实例或公网端口需要单独核对资源和批准清单，不能在 App 中填写任意端口。

## 用户与私密配置

用户拥有独立代理凭据和订阅令牌，同一用户可以在多台设备使用；额度按用户合并，不绑定设备硬件。新建用户默认停用，服务器先进入只运行私有计量 API 的预备状态，取得可信基线后才可启用代理。

在用户详情中启用、停用、加量或调整额度。**授权请求与实际实例状态分开显示**：提交停用请求不等于连接已经断开，要等服务器确认已进入预备状态或已停止；失败状态需检查，不能反复点击“启用”绕过计量、总池或撤销限制。

使用用户详情中的导出入口取得 Shadowrocket 配置、Mihomo 配置或节点链接。生产导出应包含真实服务器端点和新用户端口，不能使用 `192.0.2.10` 等示例地址。订阅 URL 含私密令牌，不能上传到公开转换网站或代码仓库。

- Shadowrocket：可导入节点链接或节点订阅，再按服务器导出的配置使用规则。
- Clash Verge Rev／Mihomo：导入该用户完整配置或对应订阅，选择规则模式和所需节点。
- VLESS 为“常用”，TUIC5 为“迅速”；按实际连接质量选择，不以名称判断速度。

轮换会更换该用户的代理凭据和订阅令牌，需要更新其全部客户端。永久撤销不可通过恢复旧版本重新授权；这些操作都只针对新用户实例，不更改旧 443 凭据。

## 用量与周期

普通用户默认每周期 **100GB**，按十进制 `100000000000` 字节计算。验收期间的临时小额度以当前服务器显示为准。“本周期加量”只增加当前周期额度，下周期清除；基础额度继续按设置生效。

上传和下载是新用户实例的**代理载荷**计数，两种协议和多台设备合并累计。它不同于服务器网卡收发总量，也不同于商家计费流量。旧 443 的使用量不在新用户账本中，不能用新账本推算整台 VPS 的实际剩余流量。

管理员“不限额”只表示不设置该用户的个人额度上限，仍然消耗同一台 VPS 的商家套餐流量。商家历史面板显示值、未核实单位或超过一小时的观察数据，不当作实时可信余额。

用户额度默认每月 **24 日 16:19（Asia/Shanghai）** 刷新。它与商家实际重置周期分别记录；续费、赠送、升级或商家预计重置到时，都不会额外刷新用户额度。只有额度原因暂停的用户，可在新周期和健康计量满足条件后恢复；手动停用、计量异常、总池保护和永久撤销仍各自生效。

计量与停用存在采样和执行延迟，不是精确到字节的硬限额。超过五秒的缺口、非预期重启或计数倒退会留下异常记录并限制普通用户，管理员不会因此自动暂停。恢复需要先核对可信样本和异常证据；未知或未分配流量不会被当作零，也不会通过清空账本解决。

## 状态和维护

邮件中心支持加密SMTP、邮箱验证、测试通知和发送历史，配置步骤见[邮件与删除用户](V3.1-邮件与删除.md)。发信由VPS执行，不依赖Mac保持开启。商家自动接口与实时计费口径尚未核实，界面继续显示其不可用或过期状态。

服务器维护入口见 [deployment/README.md](../deployment/README.md)，权限和边界见 [并行部署合同](../contracts/parallel-production.md)。恢复只针对新增程序，保留账本、永久撤销和当前有效证书；不能删除旧代理、重置全局防火墙或覆盖现有 SSH 资料。

原 443／8443 继续作为现有服务保留。只有用户另行明确验收并确认后，才会考虑独立的旧服务撤回操作。
