# QQG.NET 官方 API 调查

调查时间：2026-10-25。只读取公开官方页面、官方页面引用的 JavaScript 和公开帮助；没有读取用户密钥、Cookie、控制台 JWT，没有调用账户 API、修改密钥或设置白名单。

## 能确认什么

QQG 提供控制台 API 密钥功能，但现有公开材料不足以确认它可以查询实例流量与计费周期。

| 官方证据 | 确认的内容 | 不能据此确认的内容 |
| --- | --- | --- |
| [如何创建 API](https://www.qqg.net/plugin/26/helpTotal.htm?id=11) | 安全中心可按名称创建 API；生成后须保存关键信息。官方说明不保存原始密钥，并提醒保存 Token。 | 外部调用的鉴权签名、请求格式、查询资源与权限范围。 |
| [如何设置 IP 白名单](https://www.qqg.net/plugin/26/helpTotal.htm?id=12) | 可限制允许发起 API 调用的来源 IP。 | 白名单不等于只读权限，不能阻止已允许来源执行密钥允许的写操作。 |
| [如何查看 API 日志](https://www.qqg.net/plugin/26/helpTotal.htm?id=15) | 安全中心提供 API 远程调用记录。 | 流量字段、流量方向、单位、周期与重置时区。 |

公开帮助正文由官方[帮助目录](https://www.qqg.net/console/v1/help)和详情[11](https://www.qqg.net/console/v1/help/11)、[12](https://www.qqg.net/console/v1/help/12)、[15](https://www.qqg.net/console/v1/help/15)返回；这些链接来自官方页面实际加载的帮助脚本，没有猜测账户接口。三篇帮助均没有调用接口文档或附件链接。

## 控制台公开源码补充

- [安全中心页面](https://www.qqg.net/security.htm)创建成功的模板含 `api_url`、`token`、`private_key` 字段；本次只读模板占位符，没有读取任何用户值。
- [安全中心页面脚本](https://www.qqg.net/clientarea/template/pc/qqg_net_v13/js/security.js?v=20260911-member-6)创建请求仅提交名称。公开 UI 支持创建、删除、IP 白名单，未见每个密钥的只读 scope 配置。不能由此断言后端绝无权限配置。
- 现有 API 行尾三点菜单在页面模板中只有“删除”，没有查看已有 API 地址、重新显示 Token 或文档入口。不要为了获取文档而删除或重建现有密钥。
- [控制台请求脚本](https://www.qqg.net/clientarea/template/pc/qqg_net_v13/utils/request.js?v=20260728-20)使用浏览器登录 JWT。它属于控制台会话鉴权，不能当作外部 API 的永久鉴权说明，也不应当作为无人值守同步凭据。

## 接入前尚缺的官方材料

需要商家提供或在官方控制台找到：外部 API 基地址及版本、Token/私钥的确切用途和签名规则、仅查询权限如何配置、实例详情/流量/周期接口及响应字段、速率限制和错误码。

针对实例流量还须确认：总额、已用、剩余的单位，上传/下载/双向计费方向，周期开始/结束/下次重置的完整时间与时区、超额和续费行为。只有“500G/月”和历史页面显示的一个重置日期，不足以构造完整周期。

在这些材料到位之前，程序应继续显示“商家自动同步未验证”，保留带时间的人工观察；管理员每月24日16:19上海时间的额度规则是用户指定的程序规则，不是经 API 确认的 QQG 重置时间。

本次没有配置或测试任何外部 QQG API 凭据。向商家询问资料属于对外发送信息，应由用户明确授权后执行；本次没有发送。

## 邮箱旁证

[腾讯云官方邮箱配置说明](https://intl.cloud.tencent.com/zh/document/product/1266/71700)列出 QQ 邮箱主机 `smtp.qq.com`，465 端口使用 SSL。此处仅支持 SMTP 配置选择，不证明具体邮箱已开启 SMTP、授权码有效或邮件已投递。正文另有端口拼写不一致，本文只采用一致明确的465/SSL组合。
