# Dazzle'VPS · MYVPS

服务器上的个人 VPS 双协议服务：**VLESS REALITY（常用）**、**TUIC v5（迅速）**，配套独立用户凭据、个人载荷额度和私密 HTTPS 订阅。

**使用入口：[V3.1 服务器使用指南](docs/V3.1-服务器使用.md)。** Mac App 只连接服务器管理，不再提供本地演示环境，也不需要安装模拟 CLI。

## 当前状态

2026-10-25，现有管理后台和名单用户使用新代理运行；管理员随后自行清理了原代理。公开注册功能仍只完成本地实现，尚未上线。后续更新必须保持现有名单的代理进程、凭据和计量，不能沿用暂停普通用户的维护流程。

- 原 TCP／UDP **443** 代理与 TCP **8443** 订阅已由管理员自行清理。后续程序保留这一现状，不重建旧服务；当前名单的 **24430／24431** 代理是保护对象。
- TUIC 与 9443 使用的项目证书由 certbot 续期的短期 IP 证书经服务器本地直接 ACME 同步得到，相关文件原文见 [server/certsync/](server/certsync/)。
- 新管理员入口为 TCP／UDP **24430**，新普通用户入口为 TCP／UDP **24431**；新私密订阅使用 TCP **9443**。
- 管理复用现有 SSH 和固定控制入口，没有新建公网管理 API；计量 API 仅监听服务器回环地址。
- 普通用户默认每周期 **100GB 个人代理载荷额度**；管理员不设个人额度上限，仍受商家实际套餐约束。验收账号可能临时采用较小额度，以服务器显示为准。
- 用户额度默认每月 **24 日 16:19，Asia/Shanghai** 刷新。这是管理员规则，与商家实际计费、赠送、续费和重置分别记录。
- 邮件支持加密 SMTP、邮箱验证、测试与持久发送队列，填写授权码并验证收件地址后使用。商家实时余额与自动接口尚未核实，历史面板值不能当作当前可用流量。
- 删除用户会永久撤销凭据并归档，保留用量和审计；当前试运行资源不自动回收，不能借删除清零用量或复活旧凭据。

本程序没有旧服务退役或自动重建命令；旧目录与服务缺失须记录为真实基线，不得伪造健康状态通过检查。

公开注册、邮箱验证码登录和Mac人工启用已新增于本地源码，**尚未上线**。默认关闭新注册；普通用户中断窗口已被最新要求撤回。上线分两阶段：先由目标机一次性协调器 `deployment/coordinator.py` 在不重启现有Core的前提下交接账本writer并加每成员独立计量保护（policy仍为v1），再另行批准注册资源。协调器已通过单元测试和一次性systemd隔离演练，**尚未部署，不能视为已支持生产无中断升级**。注册确认邮件不发订阅，首次实际运行且计量可信后再发含两条订阅的开通邮件。见[保持现有代理的升级验收](docs/保持现有代理的升级验收.md)与[公开注册与人工放行](docs/公开注册与人工放行.md)。

## 配置与数据

本仓库提供脱敏源码与模板，**不能直接作为可用订阅导入**。真实服务器地址、SSH 私钥、证书私钥、节点凭据、REALITY 私钥和完整订阅令牌不得提交到公开仓库。

新服务器的配置与证书位于 `/etc/dazzle-vps`，账本位于 `/var/lib/dazzle-vps`，运行版本位于 `/opt/dazzle-vps`。这些生产资料不由本地演示数据替代，也不能通过重新生成示例配置覆盖。

两个协议共用同一服务器与出口 IP。它们不构成独立服务器备份，也不能保证所有 AI 账号、服务功能或晚高峰线路长期可用。TUIC 保持证书校验并关闭 0-RTT；“迅速”只是节点名称。
